# おぴょの ぼうけん

柴犬おぴょ（ぽろみ）が ひかりのどうくつを めざすドット絵ゲーム。
クリアご は うみがめに のって「ほしふる しま」へ。かくせい・きょうりょくプレイ・ゆめの とびら（ボスラッシュ）も。
ほしくいクジラを たおすと、うみがめで「もりの しま」へ。むしの てき14しゅ・ボス4たい・たいじゅの ダンジョン・レベル上限70。
もりの じょおうを たおすと、うみがめで「わすれられた まち」へ。どうぶつの てき14しゅ・ボス9たい（かくしボスも）・ちかすいどうと とけいとうの ダンジョン・まちの おみせ・レベル上限99。
BGMは Google Flow（Flow Music）で つくった 生演奏ふうの 曲。きいた 曲は「せってい → おんがくしつ」で いつでも きける。

あそぶ: https://poromi-oyabun.github.io/opyo-bouken/
