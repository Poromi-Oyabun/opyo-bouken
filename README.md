# おぴょの ぼうけん

柴犬おぴょ（ぽろみ）が ひかりのどうくつを めざすドット絵ゲーム。
クリアご は うみがめに のって「ほしふる しま」へ。かくせい・きょうりょくプレイ・ゆめの とびら（ボスラッシュ）も。
ほしくいクジラを たおすと、うみがめで「もりの しま」へ。むしの てき14しゅ・ボス4たい・たいじゅの ダンジョン・レベル上限70。
もりの じょおうを たおすと、うみがめで「わすれられた まち」へ。どうぶつの てき14しゅ・ボス9たい（かくしボスも）・ちかすいどうと とけいとうの ダンジョン・まちの おみせ・レベル上限99。
まちを クリアすると じくうの うずが ひらき、「きょうりゅうの じだい」へ。きょうりゅうの てき19しゅ・レア3しゅ・ボス6たい・かざんの ダンジョン・ちょうきょだい いんせきとの たたかい・しんの エクスカリバー・レベル上限150。
おうちの となりの ほんだなから「ちえの としょかん」へ。ほんの なかの せかいで、かぞえる・はかる…を ぼうけんしながら しっていく 第2部（第9章「かぞえる ほん」）。
BGMは Google Flow（Flow Music）で つくった 生演奏ふうの 曲。きいた 曲は「せってい → おんがくしつ」で いつでも きける。

あそぶ: https://poromi-oyabun.github.io/opyo-bouken/

# ぬりぬり ワンだふる！

しばいぬチームと ネコだんが すなはまを ぺんきで ぬりあう 3たい3の じんとりゲーム（90びょう）。

あそぶ: https://poromi-oyabun.github.io/opyo-bouken/nuri/

## なおす ときの きまり（再発防止）

- 公開の 前に `python3 tools/textcheck.py index.html`（誤字脱字）と `python3 tools/moji_check.py`（文字の 読みやすさ）を 通す。
- 日本語の 文章（スタッフロール・せりふ・題名）は キャンバスに 書かず、HTMLの 文字で 出す。キャンバスの 小さい 文字は スマホで 拡大すると にじんで 読めない（2026/11/08「わすれられた まち」の エンディングで 報告あり）。
